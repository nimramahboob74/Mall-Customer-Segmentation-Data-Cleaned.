# Mall Customer Segmentation – Data Cleaning & Analysis

## 📌 About the Project
This project involves cleaning and analyzing a mall customer dataset 
containing 200 customer records. The goal was to prepare raw data for 
segmentation analysis by removing inconsistencies and organizing customer 
information based on demographics and spending behavior.

## 🛠️ Tools Used
- Microsoft Excel
- Data Cleaning Techniques

## 📊 Dataset Features
| Column | Description |
|---|---|
| CustomerID | Unique customer identifier |
| Gender | Male / Female |
| Age | Customer age |
| Annual Income (k$) | Yearly income in thousands |
| Spending Score | Mall-assigned score (1–100) |

## 🔍 What I Did
- Removed duplicate and null values from the raw dataset
- Standardized column formats and data types
- Cleaned inconsistent entries in Gender and Age columns
- Prepared the cleaned dataset for further segmentation analysis

## 💡 Key Observations
- Dataset contains 200 customers across different age groups
- Spending scores vary widely across income levels
- Female customers slightly outnumber male customers in the dataset
